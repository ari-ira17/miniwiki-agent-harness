## Этап 7 — экспорт
- Admin скачивает `miniwiki-export.zip` по ссылке в шапке или `GET /api/export`.
  API гостю отвечает 401, HTML перенаправляет на вход, обе точки входа
  возвращают 403 для editor/reader. Ответ ZIP имеет `Cache-Control: no-store`.
- Архив включает все public/private страницы. UTF-8, YAML `title` и `tags`,
  исходный Markdown побайтно. Имена точно повторяют пути с добавлением `.md`.
  Повреждённые пути и дубликаты приводят к 409 до выдачи файла. На Windows
  зарезервированные имена могут препятствовать распаковке, см. ADR-009.
- На свежем образе прошли 8 целевых и 101 полный pytest (4 E2E отдельно),
  Ruff, Alembic на head без дрейфа и валидатор харнесса с локальным отчётом.
  Независимый обзор не выявил замечаний. Контракт обновлён в `docs/api.md`,
  README и OpenAPI; результаты и ограничения собраны в `docs/report/evidence.md`.
- 4 Chromium E2E прошли в изолированном Compose. Скачаны и прочитаны файлы
  родительской и дочерней страниц, подтверждены отказы остальным ролям, Swagger
  отрисован. Три PNG визуально проверены; сохранены в E09/E10 с логами.

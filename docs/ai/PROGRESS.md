## Сделано
- Харнесс, память и шесть навыков; E02/E03/E04 подтверждены ранее.
- Docker Compose app/db, FastAPI/PostgreSQL, Alembic, CI, bootstrap admin из env
  с Argon2; запуск одной командой. CRUD страниц с неизменяемыми путями,
  Markdown/preview через общий markdown-it-py → nh3, поиск/теги/навигация.
- Вход/выход, хешированные серверные сессии8ч, HttpOnly/SameSite=Lax,
  настраиваемый Secure, CSRF всех изменяющих запросов. Гость статьи не читает:
  HTML→login, API401. Reader читает только тег public, общий SQL scope
  применяется до поиска/подсчётов/пагинации/тегов/дерева. Hidden404, запрет403.
- Admin/editor выполняют CRUD/preview; только admin управляет пользователями.
  Последний активный admin защищён блокировкой, включая bootstrap и конкуренцию.
  Изменение роли/пароля, отключение/удаление отзывают сессии. Саморегистрации нет.
- Тег public — источник видимости; is_public — совместимое поле API.
  Нормализация логинов общая для создания, входа и bootstrap.
- Шаг6.3: обязательные непустые имя/фамилия, миграция0006, API/bootstrap/UI.
  Создатель и последний редактор разделены; API берёт редактора из сессии,
  не приписывает старые изменения, удаление аккаунта сохраняет страницы.
- Admin: Ирина Аристова. По прямой просьбе reader «аристова» удалён;
  новый постоянный reader ivanov — Иван Иванов, создан через admin API.
- Решения: ADR-016/017 в DECISIONS; контракты: docs/api.md и /docs.

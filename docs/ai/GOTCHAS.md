## 03.11.2026 — экранирование URL в Alembic

При обзоре шага 3.1 обнаружено: URL.create кодирует специальные символы
пароля через `%`, но Alembic ConfigParser требует экранирования `%` при
set_main_option. На шаге 3.1 добавлено replace("%", "%%"), реальная миграция
с паролем @:% прошла. На шаге 3.2 Alembic использует create_engine напрямую,
минуя интерполяцию ConfigParser; также поддерживает переданное соединение
для изолированных тестовых БД. Секреты не сохраняются в доказательствах.

03.11.2026, повтор при компиляции scripts/smoke.py: главный агент снова
не указал PYTHONPYCACHEPREFIX, получил тот же PermissionError. Повтор с
`PYTHONPYCACHEPREFIX=/private/tmp/miniwiki-pycache` прошёл. Правило закреплено
в docs/rules/workflow.md; это реальная повторная ошибка, а не ошибка приложения.

## 03.11.2026 — ранний HTTP-запрос smoke

Первый scripts/smoke.py получил RemoteDisconnected после запуска контейнера,
до готовности Uvicorn. Логи показали последующее успешное завершение startup.
Причина: ожидание готовности ловило URLError/TimeoutError, но не временное
закрытие соединения. Добавлен ConnectionError в ограниченный retry ожидания;
Compose получил healthcheck приложения. Повторный полный smoke прошёл:
bootstrap idempotence, down/up persistence, DB outage503/recovery200.
Применён systematic-debugging; исходный сбой сохранён в
`docs/report/logs/03-smoke-startup-failure.txt`.

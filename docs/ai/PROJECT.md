## Поведение
Без входа доступны авторизация и необходимые служебные маршруты, не статьи.
admin: все страницы, CRUD, пользователи и экспорт.
editor: все страницы, CRUD и изменение тегов; без пользователей и экспорта.
reader: только чтение public-страниц; фильтрация также в поиске, дереве и API.
Пользователей создаёт admin; самостоятельной регистрации нет.
Защищаем последнего активного admin от удаления и понижения роли.
Пути уникальные: сегменты из строчных латинских букв, цифр и дефисов.
Путь после создания не меняется; заголовки и текст могут быть кириллическими.
Промежуточная ветка может не иметь статьи; удаление не удаляет потомков.
Экспорт: admin скачивает ZIP всех страниц; path.md и YAML с title/tags.

## Архитектура приложения
Один сервер FastAPI: JSON REST API и HTML/HTMX-представления.
Общие сервисы и проверки доступа для API, страниц, поиска и навигации.
PostgreSQL хранит пользователей, сессии, страницы, теги и связи.
Alembic изменяет схему; Docker Compose запускает сервер и БД с volume.
Единый серверный рендер Markdown и очистка nh3 для статьи и предпросмотра.

Статус: этапы 1–6 и дополнения 6.3–6.6 завершены 05.11.2026.
Экспорт этапа 7 реализован 06.11.2026; результаты проверок в PROGRESS.md.

## Цель
Учебная MiniWiki и проектный харнесс Codex по заданию кафедры.
Источник: https://wiki.pmifi.ru/disciplines/nlp/hometasks/agent-harness
Codex вместо GigaIDE/GigaCode разрешён преподавателем со слов пользователя.

## Стек
Python3.12, FastAPI, PostgreSQL17, SQLAlchemy, Alembic, psycopg.
Jinja2/HTMX, markdown-it-py → nh3; один серверный рендер статьи/preview.
pytest/httpx, Ruff, Playwright; uv/uv.lock, Docker Compose app/db.
Argon2, серверные сессии PostgreSQL, CSRF; версии закреплены в uv.lock.

## Доступ
Без входа статьи недоступны; HTML перенаправляет на login, API возвращает401.
admin: все страницы, CRUD, пользователи и экспорт.
editor: все страницы, CRUD/теги/preview, без управления пользователями.
reader: только чтение страниц с тегом public; общий SQL scope ограничивает
также поиск/счётчики/пагинацию/теги/дерево до формирования ответа.
Тег public — источник истины; is_public вычисляется для совместимости API.
Admin создаёт пользователей, задаёт роли/пароли; саморегистрации нет.
Имя и фамилия обязательны, непусты после trim; логин отдельный, casefold.
Последний активный admin защищён от удаления/отключения/понижения, в конкуренции.
Смена роли/пароля, отключение/удаление отзывают сессии; имена доступа не меняют.
Сессия8ч, в БД только хеши токенов, cookie HttpOnly/SameSite=Lax/Secure по env.
CSRF всех изменяющих форм/API, включая login/logout/preview. Формы явно POST.
Bootstrap из env создаёт admin только при отсутствии, сохраняет пароли/данные.

## Страницы
Уникальные неизменяемые пути: сегменты строчных латинских букв, цифр, дефисов.
Кириллические заголовки/текст; промежуточная ветвь может не иметь статьи.
Удаление родителя сохраняет потомков; удаление пользователя сохраняет статьи.
Создатель и последний редактор — разные nullable FK; редактор берётся из сессии.
Правки текста/заголовка/тегов обновляют редактора/время; старым он не приписан.
CRUD API/UI, Markdown-редактор/preview, поиск title/Markdown, теги, оглавление.
Изображения по HTTP(S)-ссылкам, загрузки файлов нет; HTML очищается nh3.
Контракты в docs/api.md и /docs; /health200 либо503 без деталей отказа.

## Учебные материалы и навигация
Главная: краткое описание и каталог дисциплин по курсам, как в источнике.
Реальные материалы: /disciplines/nlp, /disciplines/programming-workshop-bachelors-5sem,
/disciplines/nlp/lectures/preprocessing. Другие дисциплины возвращают на главную.
Сохранены структура курсов,13 строк датасетов и предоставленный текст лекции.
CRISP-DM ведёт в указанную презентацию Google; предобработка — локально;
прочие исходные ссылки возвращают на свой курс. Лабораторные не импортировать.
Удалены4согласованные /demo статьи; app.demo остаётся тестовым fixture.
app.course_samples создаёт только отсутствующие материалы без перезаписи.
Раскрываемое дерево с активной ветвью, без утечки скрытых предков reader.
Карточка последнего изменения с именем/фамилией и временем; крошки/ID убраны.
Заголовки главной и статей выровнены по левому краю правой карточки;
пути скрыты в шапке статей и в результатах поиска.
Оглавление всех статей шириной 220 px на настольных экранах, на телефоне
занимает всю ширину над карточкой статьи.
Кнопка скрывает/возвращает дерево, центр ограничен1400px с полями; mobile проверен.
Боковое дерево: Бакалавриат (1–4 курс), Магистратура (1–2 курс).
На 3 курсе — полные названия дисциплин из статей, с ветками «Основная страница» и «Лекции».
Пустая папка: «Лекции отсутствуют». Заголовки текста остаются в оглавлении.
Гость на `/` перенаправляется на `/login`; после входа открываются
«Учебные дисциплины». Admin/editor создают статьи из шапки.
Пункты «Страницы» и «Курсы» убраны; поиск/теги/CRUD-маршруты сохранены.
В статье виден последний редактор; сведения о создателе доступны через API.

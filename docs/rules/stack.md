# Стек и структура

Согласованные решения — `docs/ai/DECISIONS.md` (ADR-002–005), границы
продукта — `docs/ai/PROJECT.md`. Приложение на Python 3.12 и FastAPI,
PostgreSQL, SQLAlchemy, Alembic и psycopg; HTML — Jinja2 и HTMX;
Markdown — markdown-it-py с очисткой nh3. Проверки: pytest/httpx, Ruff и
Playwright; пароли — Argon2, серверные сессии и CSRF-защита форм.
Версии пакетов закрепить после проверки совместимости при подготовке окружения.

Ожидаемые области проекта: `app/` — сервер и интерфейс, `migrations/` —
миграции, `tests/` — проверки, `scripts/` — проектные проверки, `docs/` —
требования, правила, память, архитектура и отчёт; `.agents/skills/` — навыки.
Это ориентир, а не утверждение, что все каталоги уже существуют.

Новые зависимости требуют согласования пользователя согласно родительскому
AGENTS.md. До добавления обоснуй назначение и альтернативы в ADR в
`docs/ai/DECISIONS.md`; фиксируй версии и совместимость в проекте.
Для API и HTML используй общие сервисы и проверку доступа, для статьи и
предпросмотра — единый серверный конвейер Markdown и очистки HTML.

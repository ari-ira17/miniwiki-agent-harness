# Требования задания и матрица приёмки

Источник: https://wiki.pmifi.ru/disciplines/nlp/hometasks/agent-harness
Текст прочитан в браузере 03.11.2026. Это структурированный пересказ требований.
Все проверки ниже запланированы; наличие строки в таблице не означает выполнение.

## Разрешённая адаптация

По сообщению пользователя преподаватель разрешил Codex вместо GigaIDE/GigaCode.
Инструментальные требования адаптируются: проектный `AGENTS.md`, тематические
правила в `docs/rules/`, навыки в `.agents/skills/` вместо `.gigacode/skills/`.
В отчёте явно описать замену среды и путей; не утверждать использование GigaIDE.
Глобальные настройки, навыки и другие проекты не менять.

## Дополнения проекта, не отдельные требования ТЗ

- Палитра #5D5958 / #FFFFFF / #622128 и компоновка кафедральной wiki.
- Хлебные крошки, оглавление, сведения об изменении, административный экран пользователей.
- Без гостевого чтения; без регистрации; неизменяемые ASCII-пути.
- Экспорт ZIP с YAML-frontmatter; обратный импорт не предусмотрен.
- PostgreSQL volume, миграции и повторяемая начальная настройка.
- Ruff, несколько Playwright-сценариев, проверки cookie/CSRF и опасных путей.
- Автоматический сбор доказательств с уведомлением о недоступном захвате.

Полное копирование Wiki.js, вложения, история версий, SSO, печать, публичная
регистрация и внешние интеграции в MVP не входят. MCP по ТЗ опционален.
